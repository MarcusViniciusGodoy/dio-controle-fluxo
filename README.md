# Desafio de Java básico da DIO
[![NPM](https://img.shields.io/npm/l/react)](https://github.com/MarcusViniciusGodoy/dio-controle-fluxo/blob/main/LICENSE)

## 🔨 Funcionalidades do projeto

A aplicação consiste que o usuário digite dois números inteiros, com estes dois números o sistema obtém a quantidade de interações e realizar a impressão no console dos números incrementados.

## ✔️ Técnicas e tecnologias utilizadas

As técnicas e tecnologias utilizadas pra isso são:

- `Java`

### Pré-requisitos
 Para executar este projeto, é necessário ter:
 - [Visual Studio Code](https://code.visualstudio.com/)

### Instalação
 
 1. Clone o repositório:
    ```bash
    git clone https://github.com/MarcusViniciusGodoy/dio-controle-fluxo/tree/main/DesafioControleFluxo
    ```
 
 2. Acesse o diretório do projeto:
    ```bash
    cd DesafioControleFluxo
    ```
 
 3. Abra o projeto no Visual Studio Code:
    ```bash
    code .
    ```
